# WiFi AutoConnector (Android)

An Android application developed in Kotlin as the mobile extension of my WiFi Automation project. It aims to simplify campus Wi-Fi connectivity by detecting network status and eventually assisting with captive portal login.

**Technologies:** Kotlin, Android SDK, Gradle.

**Status:** Initial app successfully built and tested on a physical Android device. Network detection and captive portal functionality are planned next.

**Goal:** Bring Wi-Fi connection assistance to Android while learning mobile development, network APIs, and Android application architecture.
